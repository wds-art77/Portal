Comment utiliser ces articles

De l'information à la solution

Ces articles exposent l'état du droit français en octobre 2026 et citent les textes applicables : Code civil, Code de commerce, Code de la consommation, Code de procédure civile, Code des procédures civiles d'exécution, Code monétaire et financier, Code général des impôts. Ils vous aident à comprendre votre situation ; ils ne remplacent pas un avis sur votre dossier.

  1. Vous lisez

    Chaque article distingue les règles entre professionnels de celles qui protègent le consommateur, et date les taux cités, revus chaque semestre, ainsi que les montants.

  2. Vous nous envoyez vos documents

    Conditions générales, devis ou contrat : un avocat les examine gratuitement et vous remet un premier avis sous 48 heures ouvrables, sans engagement.

  3. Vous décidez

    Rédaction de documents sur mesure, mise en demeure, recouvrement ou assistance devant le tribunal : vous connaissez notre prix fixe, formalisé dans une convention d'honoraires écrite, avant toute mission.
